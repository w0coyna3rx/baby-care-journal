# 【健康科普】北医三院风湿免疫科刘湘源：解读关节疼痛疑云

> 更新时间：2026-09-11 (UTC+8)

“您有过疼痛的症状吗，这疼痛啊是我们身体在出现问题的时候给我们发出的预警信号，比如牙疼，可能就是牙龈发炎了，胃疼呢，可能就是胃部出现问题了，那我今天要带您认识的这一位路先生，就是被突如其来的疼痛搅的是彻夜难眠，那么他的疼痛到底是什么原因所导致的呢？”

深夜，睡梦中的路军平被一阵剧烈的疼痛惊醒了。

路军平：“当时（脚趾）特别疼痛，反正一般人这个疼是忍受不了的。”

疼痛大约在十几秒后有所缓解，但是等早晨起来，路军平准备上班的时候，这种来自大脚趾的剧烈疼痛又突然来袭。

路军平：“当然疼痛挺厉害的，然后我爱人赶紧就给我搀床上了。”

路军平大脚趾上那种刀割般的疼痛折磨的他是苦不堪言，他甚至连动都不敢动一下了，于是，在休息了片刻之后，他赶忙到医院进行检查。“当时反正疼的时候就是肿了，红肿，上面有一包，我怀疑是不是就是有肿瘤。”

大夫在询问了路军平的症状后，让他做了X光片的检查，但是结果却并未发现他红肿的部位有肿瘤迹象，那么这问题到底出在哪里呢？大夫根据他关节出现红肿热痛的症状，怀疑他患上了类风湿关节炎，于是推荐他到风湿免疫科就诊，看看能否从那里找到答案。

“您开始是哪些地方疼？”

“脚趾头这块儿。”

“怎么个疼法？”

“（疼得）晚上睡不着觉。”

由于路军平发病的症状的确跟类风湿性关节炎很相似，于是，接诊的刘大夫便给路军平做了类风湿因子的检查。

路军平：“检查完了以后，指标正常，就是不是类风湿关节炎。”

问题究竟出在哪里呢？为了彻底的查清病因，刘大夫又让路军平做了血液检查，结果显示，他的血尿酸值比正常值高出许多。

刘湘源说：“正常值男性一般是小于416微摩尔每升，但这个病人的话，血尿酸已经高达了565微摩尔每升，所以的话是一个高尿酸血症，再结合患者发病很典型的一个急性的红、肿、热、痛，单关节受累，所以的话可以明确诊断，是一个痛风性的关节炎。”

检查结果给了路军平当头一棒，原来早在4年前他就得过痛风，但是在服用了降尿酸药物一段时间之后，就不疼了，他以为是自己的病已经好了，也就把这药给停了，也没有再做检查。但是他怎么也没有想到，这次脚趾上的红肿居然又与痛风有关。

刘湘源：“所谓的痛风，它的定义就是说，是由于嘌呤代谢紊乱和尿酸排出障碍导致的高尿酸血症，而引起的一些急性的关节炎发作，会出现单关节的急性的红、肿、热、痛，疼痛非常剧烈，这是非常典型的一个急性痛风关节炎发作的一个表现。”

而路军平就属于这种情况，因为血尿酸的沉积，使脚趾处的滑膜出现了炎症，从而导致了关节红肿，如果再不及时进行治疗，就会产生更为严重的后果。

“痛风如果说要是不及时治疗，它会引起一些严重的后果，最主要的问题就是，会累及肾脏。”刘大夫说，“擅自停药和继续大量的食用高嘌呤的食物，是路军平痛风急性发作的根本原因。而且痛风这种疾病，存在一定的间歇性，很容易让人放松警惕。长期的高尿酸血症，确实它一旦没有沉积在关节的话，它是不会出现症状的，所以很多病人的话他不去重视它，等你真正发作的时候，才意识到严重性。”

针对路军平的情况，刘大夫给他开了降血尿酸的药物，并叮嘱他一定要坚持服药，并且定期检查血尿酸值，还要注意合理的饮食。这样才能够避免痛风的反复发作。

刘湘源：“一定要控制高嘌呤饮食，最主要的就是动物的内脏、海鲜、啤酒，如果说要是有些场合你不得不喝酒，那你选择喝酒的话，你一定不能喝啤酒，最好是喝红酒，也要控制量，也不能说我敞开喝，你喝了一点以后，那你就赶快去喝一点碱性矿泉水。这样的话有助于你这个尿酸的排泄。”

刘大夫建议路军平平时多吃一些像蔬菜、水果一类的碱性食物，这样可以中和体内的尿酸。一旦出现了痛风的急性发作，也可以用一些简单的办法来缓解疼痛。“如果说晚上病人发作了，痛风关节炎发作了，应该把脚抬高，之后的话用冰敷，而不是热敷。你越是发作期间，如果说你热敷的话，是越热敷越痛。”

两个月以来，路军平一直按照刘大夫说的话，注意合理饮食，他的痛风有了很大的改善，现在他又投入到了积极的工作当中。
